# Welcome

mdbrowser reads Markdown. Type the path or web address of a Markdown file in the address bar above, or pass one on the command line.

## Somewhere to start

- [The Web of Markdown proposal](https://raw.githubusercontent.com/scripting/markdownWeb/main/readme.md) explains the idea and links to examples.
- [Dave Winer's scripting.com archive](https://raw.githubusercontent.com/scripting/markdownWeb/main/examples/readme.md) is a long run of posts in Markdown.

## Make a page your home

Open **Settings** and put the address of any Markdown page in **Home page**. It opens when the app starts, and the **Home** button (or Alt+Home) takes you back to it. Leave it empty to see this page.

## Use the keyboard

Press **Tab** to move to the first link on a page, and again for the next; **Shift+Tab** goes back. **Enter** follows the link. **PageDown**, **PageUp**, **Space**, the arrow keys, **Home** and **End** scroll. In Settings, Tab to a choice and press **Up** or **Down** to change it. **Esc** closes a panel.

## Choose how it looks

Settings also holds the reading font, the text size (or Ctrl+= and Ctrl+-, with Ctrl+0 to go back; Cmd instead of Ctrl on macOS), the spacing, whether web images load, and a light, dark, system or custom palette. Choose Custom to type your own page, text and link colours. Documents never choose their own style: how they look is up to you.
